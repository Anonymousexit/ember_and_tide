# Ember & Tide

A restaurant homepage inspired by the full-screen imagery and editorial flow of Warpigs, built with all seven supplied photographs.

Run `npm run dev`, then visit http://127.0.0.1:4173. No dependencies or build step required. `npm run check` checks JavaScript syntax.

The static site lives in `dist/`. It includes responsive layouts, a spring-based Framer-style circular cursor, parallax, staggered scroll reveals, an animated serving-cloche emblem, magnetic buttons, keyboard navigation, and reduced-motion support.

The dedicated menu opens at `#menu/food` or `#menu/drinks` with a full-screen curtain transition. Its 36 dishes and 28 drinks are organized into nine sections. Category links, browser Back/Forward, direct menu links, and returning to the previous homepage position are supported. Menu content is maintained in `dist/menu.js`.

Ember & Tide is a working concept name. The menu is illustrative. Reservations are explicitly a local preview and do not submit bookings or personal data. Replace the concept details and connect a real booking provider before launching to restaurant guests.
